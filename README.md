# 🎤 Zingen - Karaokê

Este projeto é uma landing page moderna e responsiva para o **Zingen**, um aplicativo fictício de karaokê que utiliza inteligência artificial para transformar a experiência musical. Desenvolvido durante o curso Full Stack da **Rocketseat**, o projeto foca na conversão de um design complexo em código funcional utilizando as melhores práticas de Front-end.

## ✨ Visão Geral
O Zingen oferece uma experiência de karaokê inovadora, permitindo que os usuários cantem com o vocal removido por IA e recebam feedback sobre a sua afinação. O site apresenta seções de funcionalidades, planos de assinatura e áreas de download, replicando uma interface de produto real.

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica para melhor acessibilidade e SEO.
* **CSS3**:
    * **Variáveis CSS**: Utilizadas para manter a consistência de cores, como o laranja e vermelho da marca, e tipografia Inter.
    * **CSS Grid & Flexbox**: Estruturas fundamentais para o layout responsivo das seções e cards.
    * **Design Responsivo**: Adaptado para mobile e desktop através de media queries.
    * **Arquitetura Modular**: Estilos organizados em múltiplos arquivos (hero.css, pricing.css, features.css) para facilitar a manutenção.

## 💡 Funcionalidades e Destaques
* **Remoção de Vocais por IA**: Tecnologia fictícia que separa a melodia da voz original.
* **Experiência Gamificada**: Sistema de pontuação baseado na performance vocal.
* **Letras em Tempo Real**: Sincronização detalhada para acompanhar o ritmo.
* **Planos de Assinatura**: Tabela de preços detalhada para os planos Básico, Premium e Família.
* **Interface Dark Mode**: Design elegante focado na experiência de entretenimento.
